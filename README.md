# OBSTool 配布ページ

DiscordのVC参加者とテキストチャットを、OBSのブラウザソースへ表示するWindows用ツールです。

## ダウンロード

- [最新版 OBSTool.exe](https://github.com/kusaribito9310/obs_tool_distribute/releases/latest/download/OBSTool.exe)
- [全旧バージョン対応の更新パッチ](https://github.com/kusaribito9310/obs_tool_distribute/releases/latest/download/OBSTool-update.exe)

初めて使う場合は `OBSTool.exe` をダウンロードしてください。インストールは不要です。

既に使用している場合は、OBSToolを終了してから `OBSTool-update.exe` を起動し、現在使用中のOBSTool exeを選択してください。どの旧バージョンからでも最新版へ更新でき、更新前のexeは同じフォルダへバックアップされます。

## 1.0.23の変更

- **画面の操作**：表示名を更新するボタンは上部に常設しています。Discord・デザインのどちらのタブでも、スクロールせずに押せます。
- **プリセットと初期化**：「設定」→「プリセットを書き出す」で、保存済みのチャンネル選択・デザイン・配置・画像URL・登録ユーザーをJSONファイルへ保存します。編集中の内容を含める場合は先に「保存して反映」を押してください。
- **VC画像と参加前の配置**：画像メイン表示は、空のVCも画像と名前欄の高さを確保し、全チャンネルの高さを揃えます。横幅は手動調整できますが、画像が収まる幅が下限です。長い名前・グリッドの複数行・保存した個別配置に高さが必要な場合も全チャンネルを揃えます。
- **チャットの定期更新**：Discordの定期的な権限・表示名確認でチャットの枠を作り直さないようにしました。同じ設定の通知では表示済みメッセージ、画像、スクロール位置を維持します。

## 操作方法

1. Discordデスクトップ版を起動します。
2. `OBSTool.exe` を起動します。
3. 初回だけDiscordの連携画面で承認します。
4. Discordの開発者モードを有効にし、対象サーバーを右クリックして「サーバーIDをコピー」します。
5. OBSToolへGuild IDを入力し、「取得」を押します。
6. カテゴリ、VC、テキストチャンネルを選択し、「保存して反映」を押します。
7. OBSでブラウザソースを追加し、URLへ `http://localhost:8080/overlay`、幅へ `1920`、高さへ `1080` を設定します。

表示位置は右側のプレビューでドラッグできます。VC枠・チャット枠の辺または四隅をドラッグするとサイズを変更できます。Shiftキーを押しながら辺または四隅をドラッグすると、縦横比を保って内容全体を拡大・縮小できます。Discordの表示名をすぐ反映したい場合は「表示名を更新」を押してください。

## プリセットの保存と読み込み

「設定」→「プリセットを書き出す」を押すと、チャンネル選択、デザイン、すべての配置、画像URL、事前登録ユーザーを1つのJSONファイルとして書き出せます。「設定」→「プリセットを読み込む」でそのJSONを選ぶと、設定をまとめて復元します。読み込み直後にプレビューとOBS表示へ反映されます。

Discordの認証情報、Botトークン、RPC Client Secretはプリセットに含まれません。別のPCで読み込む場合は、そのPCでDiscord連携を承認してください。チャンネル選択は、読み込みを行ったアカウントの閲覧権限に合わせて確認されます。

1.0.17以降では、15秒ごとの表示名確認中もカテゴリ・VC・テキストチャンネルの一覧と選択を維持します。「本人の閲覧権限を確認中…」へ定期的に戻る場合や選択が消える場合は最新版へ更新してください。

1.0.18以降では、画像メイン表示の参加者名について背景色・透明度・文字サイズ（8～72px）を設定できます。「デザイン設定」の「画像の名前背景」「画像の名前サイズ」で調整し、プレビューで確認してから「保存して反映」を押してください。VC枠・チャット枠・名前背景の透明度Aは、スライダーと数値欄のどちらでも0～1を0.01刻みで調整できます。表示済みチャットも、定期更新やローカル接続の一時切断では消えません。

## 動作条件

- Windows 10 / 11（64bit）
- Discordデスクトップ版
- OBS Studio
- 利用対象として承認されたDiscordアカウント

Node.jsなどの開発環境は不要です。

## Windowsの警告

コード署名証明書を設定していないため、初回起動時にWindows SmartScreenが表示される場合があります。その場合は配布元とファイル名を確認してから「詳細情報」→「実行」を選択してください。

1.0.19以降では、OBSシーンのスクリーンショットをツール右側のプレビュー背景に読み込み、映像を見ながらVC・チャットの位置とサイズを調整できます。背景画像は編集画面にだけ表示され、OBSのブラウザソースや設定ファイルには保存されません。詳しくは [操作ガイド](USER_GUIDE.md) を参照してください。
