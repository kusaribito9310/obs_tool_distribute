OBSTool 完全操作ガイド

DiscordのVC・発言状態・テキストチャットをOBSへ表示するWindows用ローカルアプリ

対象: OBSTool 1.0.17以降 / Windows 10・11（64bit）

目次 必要なもの 初回セットアップ Discord連携設定 デザイン設定 プレビューと配置 OBSへの追加 通常の使い方 権限・認証・保存 最新版への更新 トラブルシューティング 配布者・管理者向け

必要なもの

  • Windows 10 / 11（64bit）
  • Discordデスクトップ版
  • OBS Studio
  • インターネット接続
  • 対象サーバーへ導入済みの専用Bot

処理は利用者のPC上で動きます。常時稼働サーバー、Node.js、npmのインストールは不要です。ブラウザー版Discordだけでは本人認証と発言検知を利用できません。

最新版EXE 配布ページ

初回セットアップ

  1. Discordデスクトップ版を起動し、配信で使用する本人のアカウントへログインします。
  2. OBSTool.exeを任意のフォルダーへ保存して起動します。インストール操作はありません。
  3. 初回だけDiscordの連携画面を承認します。通常の再起動では保存済み認証を使用します。
  4. Discordの開発者モードを有効にし、対象サーバーを右クリックして「サーバーIDをコピー」します。
  5. Guild IDへ貼り付けて「取得」を押し、カテゴリ・VC・テキストチャンネルを選びます。
  6. 「設定を保存して反映」を押します。
SmartScreenが表示された場合は、GitHubの正式な配布ページから取得したことを確認し、「詳細情報」→「実行」を選択します。現在のexeはコード署名されていません。

Discord連携設定

利用者と表示名

画面上部には、Discordで本人確認できている利用者が表示されます。「表示名を強制更新」は、表示対象VCの参加者と表示済みチャット投稿者の名前・画像を即時取得します。自動確認は約15秒ごとです。

名前はサーバー内ニックネーム、Discord表示名、ユーザー名の順で採用します。キャラクター名を設定した場合は固定名が優先されます。

カテゴリとチャンネル

本人とBotの両方が閲覧できる対象だけが一覧へ表示されます。本人に権限がない鍵付きチャンネルは、Botが管理者でも表示されません。

項目機能
監視ボイスチャンネル参加者と発言状態を表示します。
監視テキストチャンネル新着メッセージと起動時の直近履歴を表示します。
Discordと同じDiscord上のVC位置順です。
任意に並べる上下ボタンでVCの順番を決めます。
50音順日本語名を基準にVCを並べます。

過去ログには本人とBotの「チャンネルを見る」「メッセージ履歴を読む」が必要です。新着本文にはBot側のMessage Content Intentも必要です。

キャラクター差し替え

  • 表示キャラ名: Discord名の代わりに使う固定名
  • 立ち絵/画像URL: Discordアイコンの代わりに使う画像URL

PCから直接開けるHTTPS画像を推奨します。期限付きURL、ログインが必要なURL、WebページのURLは表示できないことがあります。

デザイン設定

表示方法

  • テキストチャットを1つの枠にまとめる: 全選択チャンネルを時系列表示します。
  • VCをチャンネルごとに分割表示: VC別に独立配置できます。
  • テキストをチャンネルごとに分割表示: テキストチャンネル別に独立配置できます。
  • VC参加者を画像メインで表示: 立ち絵向け表示へ切り替えます。

「1つの枠にまとめる」と「テキストをチャンネルごとに分割表示」を両方有効にした場合は、1つの枠にまとめる設定を優先します。

画像の並べ方動作
グリッド枠内へ格子状に並べます。
横一列参加者を横方向へ並べます。
キャラ別の自由配置各参加者をドラッグできます。クリックした参加者が手前になります。

発言中の演出

「跳ねる」「発光・ネオン」「拡大」は複数同時に使えます。拡大倍率は1.00～2.00倍、発光色と発光対象、非発言時グレーの強さも設定できます。

色と透明度

VC枠・チャット枠の背景色、透明度、文字色を個別に設定できます。透明度Aは0で完全透明、1で不透明です。

プレビューと配置

右側のプレビューは1920×1080基準です。

操作結果
枠をドラッグ位置を移動します。
辺・四隅をドラッグ幅・高さを変更します。
Shift＋辺・四隅をドラッグ縦横比を保って内容全体を拡大・縮小します。
自由配置のキャラをドラッグ参加者を個別に移動します。
位置リセット枠とキャラクター個別配置を初期位置へ戻します。

数値欄ではX・Y座標、横幅、高さ、拡大率、立ち絵の高さ、画像の重なりを調整できます。高さ0は自動です。分割表示では上部のチャンネルボタンから編集対象を選びます。

設定欄とプレビュー欄の間にある縦線を左右へドラッグすると、画面上の表示幅を調整できます。この幅調整はOBSの配置値には影響しません。

プレビューへの変更は即時反映されます。再起動後も残すには「設定を保存して反映」を押してください。

OBSへの追加

  1. OBSToolを起動したままにします。
  2. OBSで「ブラウザ」ソースを追加します。
  3. URLへ http://localhost:8080/overlay を入力します。
  4. 幅を1920、高さを1080にします。
  5. 必要に応じて「現在のページのキャッシュを更新」を実行します。
OBS用URLへ?mode=editorは付けません。これはOBSTool内部の編集プレビュー専用です。OBSToolを終了するとOBS表示も停止します。

通常の使い方

Discordデスクトップ版 → OBSTool → OBS Studioの順で起動します。

「一時停止」は通常の状態配信を止め、「再開する」で現在状態と履歴を再送します。権限剥奪、アカウント変更、Discord切断時は安全のため一時停止中でも表示を解除します。

チャットは時間経過、名前更新、VC状態更新、配置・テーマ変更では消えません。選択解除、権限解除、切断、OBSブラウザソースの再読み込み、アプリ再起動では消える場合があります。

権限・認証・保存の仕組み

閲覧権限

Discordデスクトップ版で本人を確認し、Bot経由で本人のロールとチャンネル個別権限を判定します。権限は約30秒ごとにも確認します。一時的な通信失敗では確認済み表示を維持し、実際の権限変更・アクセス拒否・アカウント変更・DiscordまたはBot切断時に解除します。

保存場所

内容場所
表示・チャンネル設定%APPDATA%\obs-discord-overlay\user_config.json
暗号化Discord認証%APPDATA%\obs-discord-overlay\rpc-auth.bin
現在のログ%APPDATA%\obs-discord-overlay\logs\app.log
前回ログ%APPDATA%\obs-discord-overlay\logs\app.previous.log

Win + Rでパスを貼り付けると開けます。認証ファイルは同じWindowsユーザーでのみ復号できます。

最新版への更新

最新版の更新パッチ

  1. OBSToolを終了します。
  2. OBSTool-update.exeを起動します。
  3. 「参照」で現在使用しているOBSTool exeを選びます。
  4. 「更新する」を押します。

どの旧版からでもパッチ内蔵の最新版へ直接更新します。更新前のexeは同じフォルダーへ.bakとして保存され、AppDataの設定と認証は維持されます。パッチは将来版をオンライン取得しないため、毎回最新のパッチを取得してください。

トラブルシューティング

SmartScreenで「WindowsによってPCが保護されました」

正式なGitHub配布ページから取得したことを確認し、「詳細情報」→「実行」を選択します。未署名exeのため警告される場合があります。自己署名だけでは配布先で信頼登録しない限り解消しません。

起動しない / 8080番ポート使用中
  • 既存のOBSToolを終了します。
  • 開発版はターミナルでCtrl + Cを押します。
  • タスクマネージャーで残ったOBSTool/Electronを確認します。
  • 8080番を使う別アプリを終了します。
Discord認証を何度も求められる
  1. Discordデスクトップ版へ本人のアカウントでログインします。
  2. Discordを先に、OBSToolを後に起動します。
  3. 再承認する場合はOBSTool終了後に%APPDATA%\obs-discord-overlay\rpc-auth.binだけを削除します。
「本人の閲覧権限を確認中…」から進まない
  • 1.0.17以降へ更新します。
  • Botが対象サーバーでオンラインか確認します。
  • 本人のサーバー参加とサーバーIDを確認します。
  • Discord・ネットワーク接続を確認し、「取得」を押し直します。
カテゴリやチャンネルが出ない

本人とBotの両方に「チャンネルを見る」が必要です。カテゴリと子チャンネルの権限が非同期なら子側も確認します。ロール変更後は最大30秒ほど待つか再取得します。

選択が消える / 元に戻る

1.0.17以降へ更新し、最後に「設定を保存して反映」を押します。実際に閲覧権限が外れた対象は安全のため除外されます。1.0.17以降は定期確認、初回取得、Bot再接続、保存前の再取得で選択を維持します。

OBSに何も表示されない
  • OBSToolを起動したままにします。
  • URLをhttp://localhost:8080/overlay、幅1920、高さ1080にします。
  • 対象チャンネルを選択して保存します。
  • ブラウザソースのキャッシュを更新します。
VCの発言演出が動かない

Discordデスクトップ版、対象VCの選択、演出チェック、RPC接続を確認します。ログにRPC切断がないかも確認してください。

テキストチャットが表示されない

選択と保存、本人・Botの閲覧権限、履歴権限、BotのMessage Content Intentを確認します。Bot自身の投稿は表示しません。

表示名が変わらない

「表示名を強制更新」を押します。キャラクター名が設定されている場合は固定名が優先されます。

画像・立ち絵が表示されない

ログイン不要で直接開けるHTTPS画像URLを使います。URL期限、アクセス制限、WebページURLになっていないか確認し、OBSキャッシュを更新します。

チャットが消えた

時間経過だけでは消えません。権限・選択解除、切断、OBS再読み込み、アプリ再起動では消えます。起動時は選択チャンネルの直近履歴を最大5件ずつ取得します。

更新パッチが失敗する
  • 対象OBSToolを終了します。
  • 対象exe名にOBSToolを含めます。
  • 書き込み権限と空き容量を確認します。
  • 最新パッチでも失敗する場合は通常版EXEへ置き換えます。
ログが文字化けする

1.0.16以降のnpm startはUTF-8へ切り替えます。配布版や外部収集で文字化けするときは、UTF-8 BOM付きの%APPDATA%\obs-discord-overlay\logs\app.logをメモ帳で開きます。

設定を初期化したい

OBSToolを終了してAppDataフォルダーをバックアップします。表示設定はuser_config.json、Discord承認はrpc-auth.binを削除すると個別に初期化できます。

問題報告に必要な情報

  • OBSToolのバージョン
  • 発生時刻
  • 操作手順
  • 画面メッセージ
  • app.log
user_config.jsonには設定や認証情報が含まれる場合があります。そのまま公開しないでください。

配布者・管理者向け

Discord側

  • DiscordアプリケーションとBotを用意し、対象サーバーへ一度招待します。
  • 必要チャンネルの閲覧・履歴取得権限を付与します。
  • Message Content Intentを有効にします。
  • RPC/OAuthでrpcとidentifyを利用できる状態にします。

Botの管理者権限は必須ではなく、OBSToolのDiscordスラッシュコマンドはありません。

環境変数

DISCORD_BOT_TOKEN=
DISCORD_RPC_CLIENT_ID=
DISCORD_RPC_CLIENT_SECRET=
DISCORD_RPC_REDIRECT_URI=http://127.0.0.1
現在は.envをexeへ同梱します。画面で非表示でもBot TokenやClient Secretを抽出できるため、信頼できる相手だけへ配布してください。
